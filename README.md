# 賽程自動轉換行前通知單與公假單產生器

本專案為一個輕量化、免安裝的單頁 Web 應用程式，專為學校運動隊伍、社團與帶隊教師設計。能自動將比賽個人賽程文字或賽程圖片，轉換為符合標準 A4 格式的「行前通知單」與下方可撕式的「公假單回條」。

---

## 🌟 功能亮點

1. **圖片辨識 (OCR) 支援**：直接上傳賽程圖檔（如 Line / 官網截圖），內部整合 Tesseract.js 繁體中文辨識技術自動擷取賽程文字。
2. **靈活欄位設定**：可自由調整比賽名稱、地點、比賽日期、學校集合時間與自行前往時間。
3. **自動解析選手賽程**：依選手姓名自動歸類低/中/高年級單雙打項目與比賽時間點。
4. **精準排版與 A4 列印**：
   - 上半部：行前通知事項與兩日時間對照表格。
   - 下半部：帶有虛線切割標示的導師公假單回條，內建請假時間勾選框（☐）與導師簽章區。
   - 內建 `@media print` 最佳化樣式，列印或另存 PDF 時會自動分頁。

---

## 🚀 快速開始

### 1. 本地開啟
無須 Node.js 環境，直接以瀏覽器開啟 `index.html` 即可開始使用。

### 2. 部署到 GitHub Pages
1. 將本專案推送到 GitHub Repository。
2. 進入 Repository 頁面 ➔ **Settings** ➔ **Pages**。
3. 在 **Branch** 選擇 `main` 並儲存，即可獲得免費的線上使用網址。
